# Qwen CLI

## Registro histórico

La documentación del proyecto registra el uso de una herramienta/agente CLI basado en Qwen durante una fase temprana para refactors, documentación y depuración.

## Por qué fue relevante

El salto conceptual respecto a un chat web fue permitir que un agente trabajase con archivos y comandos del entorno. Ese patrón —agente con acceso operativo al repositorio— se mantuvo después con otras herramientas.

## Qué no se afirma

La versión anterior de esta ficha atribuía una fecha exacta de “cierre” y una causa comercial al servicio. Esa explicación no estaba respaldada por evidencia conservada en el repositorio y se elimina.

Tampoco se asume que “Qwen CLI” sea hoy el mismo producto, tenga el mismo acceso o conserve las mismas condiciones.

## Lección

No basar un workflow crítico en la continuidad de un proveedor concreto. El repositorio, Git y los contratos del proyecto deben permitir cambiar de agente sin perder trazabilidad.
