# Devin

## Qué es relevante para el PFC

Devin, desarrollado por Cognition, se utilizó en una etapa como agente remoto que podía trabajar sobre un repositorio y proponer cambios mediante Git/GitHub.

La documentación histórica asocia a ese flujo tareas de limpieza, fixes y mejoras. Esos resultados deben comprobarse en el historial Git cuando se necesite atribución exacta; esta ficha no convierte una lista antigua de commits en evidencia automática.

## Ventaja

El modelo “tarea → cambios versionados → revisión” encaja bien con trabajo delegable y facilita revisar el diff antes de integrar.

## Riesgo

La autonomía no elimina la necesidad de supervisión. Un agente puede ampliar alcance, elegir una suposición incorrecta o modificar más de lo necesario.

## Corrección histórica

Se elimina la afirmación de que Cognition sea “creadora de GitHub Copilot”. GitHub Copilot no es un producto de Cognition.

> Condiciones comerciales y capacidades actuales de Devin se consideran información externa y cambiante.
