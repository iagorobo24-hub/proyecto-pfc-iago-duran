# GitHub Copilot

## Uso en el PFC

Se utilizó como asistencia dentro del editor para completar código repetitivo, pequeñas funciones, estilos y documentación mientras se desarrollaba la SPA.

## Cuándo resultó útil

- boilerplate de React;
- transformaciones de datos sencillas;
- CSS y utilidades;
- completar patrones ya definidos en el archivo.

## Riesgos observados

El autocompletado puede producir una continuación plausible que no respete el negocio, los contratos del repositorio o la versión real de una API. Aceptar una sugerencia con `Tab` no sustituye la revisión.

## Lección

Copilot funcionó mejor cuando la arquitectura y el contrato ya estaban claros. Para decisiones de diseño o bugs que cruzaban varias capas fueron más útiles herramientas capaces de leer más contexto y ejecutar validaciones.
