# Windsurf

## Uso en el PFC

Windsurf se utilizó como editor con asistencia contextual para trabajar sobre archivos existentes, generar componentes y realizar iteraciones rápidas sobre la interfaz.

## Aportaciones

- acceso al codebase desde el entorno de edición;
- autocompletado y chat contextual;
- iteración rápida sobre componentes React;
- ayuda en refactors locales.

## Limitaciones

Tener acceso al repositorio no convierte una propuesta en correcta. Los cambios seguían necesitando build, pruebas, revisión visual y control de alcance.

## Lección

La principal mejora respecto a un chat aislado fue reducir el coste de trasladar contexto manualmente. Para tareas con Git, ejecución sistemática de comandos o auditorías amplias se complementó con agentes de terminal.
