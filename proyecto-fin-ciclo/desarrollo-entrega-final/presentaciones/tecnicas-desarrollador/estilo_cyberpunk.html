PROYECTO PFC

Ecosistema web con IA para técnicos electricistas

[ CONCEPT ]

Un conjunto unificado de 8 herramientas operativas diseñado para digitalizar y simplificar el flujo de trabajo de técnicos e ingenieros del sector eléctrico.

Construido mediante metodologías ágiles y asistencia de modelos avanzados de Inteligencia Artificial Generativa.

MÓDULOS DE SISTEMA

8 herramientas integradas en una SPA React

01. Fichas Técnicas: Navegación por catálogo y enriquecimiento con IA.

02. Simulador Almacén: Entrenamiento de ciclo de pedidos con incidencias.

03. Incidencias: Diagnóstico y registro guiado por algoritmos de IA.

04. KPI Logístico: Cálculo en tiempo real de eficiencia y reporte semáforo.

05. Presupuestos: Cotizador integrado con precios reales del catálogo.

06. Formación Interna: Matriz de habilidades y generación de planes.

07. SONEX Chatbot: Asistente conversacional experto en normativas.

08. Dashboard Global: Agregador de métricas y acceso centralizado.

STACK TECNOLÓGICO

Arquitectura desacoplada y escalable

[ FRONTEND // CLIENT ]

• React 19 + Vite 7: Base SPA ultra rápida con empaquetado de última generación.

• React Router DOM v7: Manejo de enrutamiento dinámico y protección de accesos.

• CSS Modules + custom variables: Diseño visual adaptativo y soporte nativo de modo oscuro.

[ CLOUD // BACKEND ]

• Supabase Cloud: PostgreSQL para catálogo masivo y Supabase Auth para OAuth.

• OpenRouter API + Vercel Functions: Gateway proxy de procesamiento serverless de IA.

• Hosting Vercel: Despliegue continuo (CI/CD) automatizado desde GitHub.
