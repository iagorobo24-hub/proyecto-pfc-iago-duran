Proyecto PFC: Core Monitor

Resumen global e innovaciones

[ PROPUESTA ]

El proyecto implementa un ecosistema web con **8 herramientas industriales** acopladas bajo una SPA React y conectado a una base de datos de catálogo PostgreSQL hospedada en Supabase.

El objetivo es digitalizar la operatoria de los electricistas en planta de forma unificada.
