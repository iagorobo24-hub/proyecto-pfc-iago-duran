Presentación del Proyecto y Objetivos

Concepto y Valor Diferencial

Suite web (SPA) con 8 herramientas de negocio para el sector de distribución eléctrica (Sonepar). El proyecto destaca por su documentación detallada de la metodología humano-IA para el sector educativo.

Objetivos de Ingeniería

  • ⚡ Funcionalidad (OE1): 7 módulos clave (catálogo, picking, incidencias, presupuestos, etc.).
  • 🤖 Metodología (OE2): Estudio de 15+ herramientas de IA y flujo de trabajo CLI.
  • 🔌 Calidad y Coste (OE3/5): Stack robusto React 19 + Supabase a coste cero.

05B / Capítulo 4

Resiliencia y Capas de Seguridad

Resiliencia de Red

• StubClient Proxy: Intercepta fallos de Supabase en supabaseClient.js de forma automática.

• Mock Fallback: Desvío instantáneo a Mock Data local estructurada para evitar pantallas en blanco.

• Sincronización: LocalStorage y hook useMemoriaUsuario para guardar y subir datos de usuario.

Seguridad y Diseño UI/UX

  • Seguridad RLS: Datos aislados por usuario en base de datos.
  • Vercel Serverless: Funciones proxy para ocultar la API key de OpenRouter.
  • Diseño y Tema: CSS Variables con transiciones circulares para alternar modo claro/oscuro.

08C / Capítulo 7

Aprendizajes y Errores de Ingeniería

Casos de Estudio

🔑 API Key Expuesta: Clave de Anthropic expuesta en frontend. Corregido mediante Vercel Serverless Functions como proxy seguro.

📦 Base de Datos: Bloqueo por límites de escritura de Firestore Spark. Corregido migrando a Supabase PostgreSQL.

Bugs Silenciosos y Aciertos

🐛 Bug de validación JSON: Validador que retornaba array en lugar de boolean, descartando respuestas. Detectado por code review del flujo de datos.

💡 Aciertos: Modularidad a base de Custom Hooks y uso de CSS Modules (cero runtime overhead).
