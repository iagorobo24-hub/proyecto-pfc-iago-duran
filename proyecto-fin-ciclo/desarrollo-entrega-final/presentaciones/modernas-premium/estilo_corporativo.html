Resumen Ejecutivo

Proyecto PFC: Suite Técnica Digital

Propuesta de Valor

Ecosistema web (SPA) que reúne 8 herramientas clave para facilitar las operaciones rutinarias de técnicos electricistas de campo y de logística.

Desarrollado integralmente con una metodología ágil asistida por Inteligencia Artificial y con un coste total de 0€.

Módulos de la Aplicación

8 Herramientas Integradas

Gestión Operativa

  • Fichas Técnicas: Catálogo masivo enriquecido con IA.
  • Simulador de Almacén: Entrenamiento gamificado de pedidos.
  • Gestión de Incidencias: Diagnóstico y reporte con IA.
  • KPIs Logísticos: Análisis de turnos mediante semáforos visuales.

Soporte y Consultas

  • Presupuestos: Cotizaciones con exportación a PDF.
  • Formación: Control de capacitación y matriz con IA.
  • Asistente SONEX: Chatbot experto en reglamentos técnicos.
  • Dashboard Global: Consolidado e integrador de KPIs.
Arquitectura de Sistemas

Estructura Tecnológica

Frontend del Cliente

• React 19 + Vite 7: Framework modular rápido con empaquetamiento optimizado.

• React Router DOM 7: Enrutamiento jerárquico y pasarelas de autenticación.

• CSS Modules: Estilizado modular que soporta de forma nativa la alternancia de modo oscuro.

Servicios Cloud y Base de Datos

• Supabase (PostgreSQL): Base de datos relacional robusta que hospeda el catálogo.

• Gateway OpenRouter: Acceso federado a modelos LLM avanzados (Claude 3.5, DeepSeek, Qwen).

• Vercel & GitHub: Integración y despliegue continuo y gratuito.

Resultados y Aprendizaje

Impacto de la Inteligencia Artificial

La IA acelera sustancialmente el ciclo de desarrollo. Un alumno de ciclo sin formación avanzada previa de software es capaz de modelar una aplicación comercial real, delegando la complejidad de sintaxis de código en los modelos y enfocándose en la resolución de problemas y la lógica de negocio.

Lecciones Críticas

• La normalización taxonómica de los datos de origen es el factor de éxito más relevante.

• La cobertura del testing es obligatoria para realizar refactorizaciones seguras.
