01 / Concepto

PROYECTO PFC

INNOVACIÓN

Suite de 8 Módulos Web

Un ecosistema completo de herramientas integradas en una SPA diseñado específicamente para los desafíos logísticos y técnicos diarios que enfrentan los técnicos de distribución.

EFICIENCIA

Desarrollado con IA

Construido a coste financiero cero aplicando una metodología de prompting iterativo sobre IDEs generativos de última generación. Todo el código base y los tests están creados con asistencia inteligente.

02 / Módulos

Servicios y Módulos

Herramientas Operacionales

• Fichas Técnicas: Catálogo e indexador de referencias.

• Almacén: Simulador dinámico con gamificación.

• Incidencias: Diagnóstico preventivo con IA.

• KPI Logístico: Fórmulas y semáforos integrados.

Herramientas de Apoyo

• Presupuestos: Cotizador dinámico en PDF.

• Formación: Matriz de competencias automatizada.

• SONEX: Asistente conversacional con IA.

• Dashboard Global: Resumen global de operaciones.

03 / Arquitectura

Stack de Tecnología

Arquitectura Cliente

• Vite 7 + React 19: Ejecución ultrarrápida y renderizado reactivo eficiente.

• React Router 7: Enrutamiento protegido por roles.

• CSS Modules: Estilos limpios y scoped con variables de diseño personalizadas.

Servicios Cloud

• Supabase (PostgreSQL): Gestión masiva del catálogo de productos.

• OpenRouter API: Acceso a modelos LLM avanzados vía Vercel Serverless Functions.

• Vercel (CI/CD): Alojamiento gratuito de alto rendimiento.

06 / Conclusión

Metodología y Lecciones

Eficiencia de Desarrollo

La IA permite cambiar el enfoque tradicional del desarrollo de software: el programador pasa de escribir líneas de código manualmente a actuar como un arquitecto y corrector lógico, optimizando la modularización y el diseño de la base de datos.

Conclusiones Clave

• La taxonomía y normalización de la base de datos son críticas para que los agentes inteligentes puedan programar y hacer consultas efectivas sin errores.

• El testing automatizado sistemático es vital para prevenir regresiones lógicas.
