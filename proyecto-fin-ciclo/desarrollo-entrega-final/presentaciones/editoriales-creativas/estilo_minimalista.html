05

ARQUITECTURA Y STACK.

Estructura cliente SPA modular y migración a base de datos unificada.

Estructura Cliente

Aplicación SPA construida con React 19 y Vite 7. Acceso protegido unificado bajo un AppShell que gestiona 14 rutas internas de negocio mediante CSS Modules aislados.

Backend y Datos

Migración completa de Firestore a Supabase (PostgreSQL + Auth). Consultas relacionales optimizadas con paginación `.range()` y búsquedas nativas con GIN full-text indexes.

05B

RESILIENCIA Y SEGURIDAD.

Tolerancia a cortes de red, aislamiento RLS y diseño UI/UX.

Resiliencia de Red

Proxy `createStubClient` que intercepta caídas de Supabase y desvía llamadas a Mock Data local de forma transparente. Sincronización offline en localStorage.

Seguridad y Diseño

Aislamiento estricto de datos con Row Level Security (RLS) en base de datos. Serverless gateway proxy en Vercel para API key y rate limiting. Transiciones animadas de modo oscuro.
