PRESENTACIÓN DEL PROYECTO.

Concepto del proyecto, propuesta de valor y objetivos clave.

CONCEPTO Y PROPUESTA

Proyecto PFC: Aplicación web (SPA) con 8 herramientas para técnicos del sector de distribución eléctrica.

Diferenciador: Metodología de desarrollo asistida por IA (humano-IA) con lecciones documentadas para otros estudiantes.

OBJETIVOS TÉCNICOS

⚡ OE1 (Funcionalidad): 7 módulos (catálogo, picking, incidencias, KPIs, presupuestos, competencias y chatbot).

🤖 OE2 (Metodología): Catalogar 15+ herramientas IA y workflow CLI.

🔌 OE3/5 (Calidad/Coste): React 19 + Supabase PostgreSQL con coste de 0.00€.

02B

TECNOLOGÍAS Y ÁMBITO.

Métricas, tecnologías principales y límites del proyecto.

MÉTRICAS Y STACK CORE

💻 Core Stack: React 19 + Vite 7 + Supabase + Vercel.

📊 Métricas: 4.689 productos indexados y 7 herramientas SPA.

🧪 Testing: 425 tests (270 Vitest / 155 Playwright E2E).

💰 Presupuesto: 0.00€ coste de licencias e infraestructura.

RESILIENCIA Y SEGURIDAD.

RESILIENCIA DE RED

💾 Offline Sync: Guardado en local con localStorage.

🔄 Persistencia: Sincronización automática de datos al recuperar red.

SEGURIDAD Y DISEÑO UI

🌐 Vercel Serverless: Proxy de API para ocultar la clave de OpenRouter.

🌓 UI/UX: Paleta corporativa Sonepar y transiciones de modo oscuro fluidas.

08C

ERRORES Y APRENDIZAJES.

Resolución de fallos críticos y lecciones de arquitectura.

ERRORES CRÍTICOS Y SOLUCIÓN

🔑 API Key expuesta: Clave hardcodeada en frontend. Solución: Proxy Serverless en Vercel.

📦 Base de Datos: Bloqueo por límites de escritura Firestore e importaciones fallidas. Solución: Normalización y migración a Supabase.

BUGS Y APRENDIZAJES

🐛 Bug del Validador: El callback devolvía array en lugar de boolean, descartando respuestas de SONEX. Resuelto por Code Review.

💡 Aciertos: Uso de CSS Modules (cero runtime overhead) y modularización por hooks personalizados.

09

OPERATIVA CORE.

Manuales de uso para los procesos diarios de la suite de negocio.

CATÁLOGO Y PRESUPUESTOS

🔍 Fichas Técnicas: Navegación jerárquica en 8 niveles y autocompletado en catálogo. Integración con información extendida por IA (cargando, completado, fallback silencioso).

📄 Presupuestos: Enlace directo de productos sin búsquedas previas de referencias. Cálculos automáticos de Subtotal, IVA (21%) y Total con exportación PDF en un clic.

CONTROL DE RENDIMIENTO

🎓 Gestión de Formación: Matriz de competencias en tiempo real para visualizar cursos completados por empleados y sugerir planes de formación personalizados.

📊 Dashboard de KPIs: Semáforo tricolor de control logístico: Verde (dentro del objetivo - mantener), Amarillo (cerca del límite - monitorizar) y Rojo (fuera del objetivo - actuar).
