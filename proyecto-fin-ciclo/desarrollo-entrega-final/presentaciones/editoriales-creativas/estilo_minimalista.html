02

MÓDULOS DE APLICACIÓN.

8 herramientas diseñadas para solventar problemas del día a día industrial.

OPERACIONES

• Fichas: Buscador de catálogo masivo con 400K+ refs.

• Almacén: Simulador de pedidos gamificado con cronómetro.

• Incidencias: Diagnósticos de fallos por IA.

• KPIs: Análisis de turnos con semáforos.

APOYO Y CONSULTA

• Presupuestos: Cotizador dinámico en PDF.

• Formación: Gestión de capacitación por IA.

• SONEX Chat: Asistente experto en normativas.

• Global Dashboard: Vista unificada de KPIs.

03

ARQUITECTURA DE SOFTWARE.

Estructura moderna desacoplada con comunicación asíncrona.

FRONTEND

• Core: React 19 + Vite 7

• Router: React Router v7

• Estilos: CSS Modules scoped y variables

SERVICIOS CLOUD

• Base de Datos: Supabase PostgreSQL
