MÓDULOS

LAS 8 HERRAMIENTAS

LÓGICA OPERATIVA

• Fichas Técnicas: Navegación de catálogo.

• Almacén: Simulador de pedidos dinámico.

• Incidencias: Diagnósticos de fallos por IA.

• KPIs Logísticos: Panel KPI con semáforos.

SOPORTE Y CHAT

• Presupuestos: Cotizador de catálogo en PDF.

• Formación: Matriz competencias con IA.

• Chatbot SONEX: Asistente conversacional.

• Dashboard Global: Resumen agregador.

TECNOLOGÍA

ARQUITECTURA DESACOPLADA

FRONTEND

• Core SPA basado en React 19 y Vite 7.

• Enrutador modular con React Router 7.

• Módulos CSS aislados para modo oscuro nativo.

BACKEND

• Supabase Cloud: PostgreSQL para catálogo.

• OpenRouter API: Gateway de modelos LLM.

• Hosting Vercel: Servidor serverless y CDN global.
