Visión General

El proyecto en una mirada

Un ecosistema completo de aplicaciones web pensado para la gestión técnica de un almacén industrial del sector eléctrico. Desde un catálogo de miles de referencias hasta un asistente IA que lee planos técnicos, pasando por simulación logística y cuadros de mando.

Todo construido con tecnología web moderna, sin coste de licencias, demostrando lo que se puede lograr combinando formación profesional y herramientas de última generación.

Impacto Formativo

Aprendizaje aplicado

Este proyecto ha sido el vehículo para poner en práctica tecnologías y metodologías del mundo profesional.

Competencias técnicas

  • Desarrollo full-stack con React y ecosistema moderno
  • Integración de IA generativa en producto real
  • Bases de datos relacionales y no relacionales (Supabase + Firestore)
  • Testing automatizado E2E y unitario
  • Despliegue serverless y CI/CD con Vercel

Metodologías profesionales

  • Git con conventional commits y ramas por funcionalidad
  • Arquitectura modular y separación de responsabilidades
  • Documentación técnica y de producto
  • UX/UI responsive con modo oscuro y accesibilidad
  • Seguridad: autenticación OAuth, RLS, buenas prácticas
Conclusiones
