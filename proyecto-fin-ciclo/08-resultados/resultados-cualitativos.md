# Resultados Cualitativos

## Introducción

Este documento evalúa el valor percibido del proyecto desde diferentes perspectivas: la experiencia del usuario, la utilidad para Sonepar, y el aprendizaje personal.

---

## Valor para el usuario

### Lo que funciona bien

| Aspecto | Feedback |
|---------|----------|
| **Navegación del catálogo** | Intuitiva, jerarquía clara |
| **SONEX** | Respuestas útiles, detección de productos |
| **Diseño responsive** | Funciona bien en móvil |
| **Modo oscuro** | Implementación fluida |
| **Velocidad de carga** | Acceptable (<3s) |

### Áreas de mejora

| Aspecto | Problema |
|---------|----------|
| **Imágenes de productos** | ~25% no tienen imagen |
| **Búsqueda** | Lenta con 400K productos |
| **Precios** | No disponibles para todos los productos |
| **Actualización del catálogo** | Requiere proceso manual |

---

## Valor para Sonepar

### Lo que aporta

1. **Acceso centralizado** — Toda la información en un solo lugar
2. **Catálogo real** — Datos scrapeados de su propia web
3. **Asistente técnico** — Resolución de dudas 24/7
4. **Presupuestos** — Herramienta para comerciales
5. **Formación** — Seguimiento de competencias

### Limitaciones actuales

1. **No hay integración** con sus sistemas (SAP, ERP)
2. **No es oficial** — Es un proyecto académico, no un producto
3. **Sin soporte** — No hay equipo mantenimiento

### Lo que mejoraría

1. **Tests desde el principio**
2. **Validación con usuarios reales**
