05Proceso de desarrollo

De artefactos sueltos a producto en producción

El proyecto evolucionó en 5 fases bien diferenciadas, cada una con su objetivo y sus entregables verificables.

Fase 0
Artefactos individuales
7 herramientas como archivos JSX independientes generados con Claude Web. Validación de conceptos sin compromiso.
Fase 1
Migración a SPA
Vite + React Router + AppShell. Sistema de componentes reutilizables y rutas centralizadas.
Fase 2
Sistema de diseño
CSS Modules, modo oscuro, tokens de diseño y estandarización visual corporativa.
Fase 3
Auth + Persistencia
Firebase Auth con Google Sign-In, rutas protegidas, migración a Supabase/PostgreSQL.
Fase 4
Catálogo masivo
Scraping con Playwright de 400K+ productos, sincronización y optimización de queries.

08Impacto educativo

Un proyecto, dos audiencias

El PFC no termina con la entrega: deja materiales reutilizables para futuros alumnos y competencias nuevas en el currículum del autor.

Materiales generados

  • 15 fichas técnicas de herramientas IA documentadas paso a paso
  • Manual de 4 sesiones para profesores de FP
  • Rúbricas de evaluación detalladas y reutilizables
  • Biblioteca de prompts exitosos catalogados
  • Metodología "Vibe Coding" explicada desde cero

Competencias adquiridas

  • React 19 moderno: Hooks, Context, Router, Suspense
  • PostgreSQL + Row Level Security con Supabase
  • Trabajo profesional con IA generativa y agentes CLI
  • Web scraping ético con Playwright
  • Deployment continuo, monitoring y Serverless

Demuestra que un estudiante de FP puede construir una solución profesional sin experiencia previa en programación web — solo con curiosidad y las herramientas adecuadas.
